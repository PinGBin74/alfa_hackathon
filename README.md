# Alfa News Insights

Сервис персонализированной новостной аналитики для руководителей крупного бизнеса (кейс хакатона «Альфа Будущее»).
Превращает поток внешних новостей и аналитики Альфа-Банка в бизнес-инсайты: что произошло, почему важно для конкретной компании, какие риски и возможности, как это оценивает банк.

> Статус: каркас. Разделы ниже заполнять по мере реализации.

## Архитектура

```
Источники (RSS/HTML, PDF банка) -> ingestion -> Postgres + pgvector
                                                  |
Клиент (CSV) -> профиль + граф контрагентов ------+
                                                  v
                      Агент: план -> инструменты -> самопроверка -> инсайт (JSON)
                                                  |
                           FastAPI  <---  frontend (имитация Альфа-Бизнес)
```

Подробнее: `docs/architecture.md`.

## Требования к окружению
- Docker + Docker Compose
- (для разработки) Python 3.12, uv, Node 20+

## Быстрый старт
```bash
cp .env.example .env        # заполнить LLM_BASE_URL и LLM_API_KEY
make up                     # db + backend + worker + frontend
make seed                   # загрузка CSV из data/raw (полная замена; синтетика: --dir data/synthetic)
make ingest                 # разовый сбор новостей и индексация аналитики
```
- API: http://localhost:8000 (Swagger: `/docs`)
- Frontend: http://localhost:3000

## Конфигурация
Все переменные описаны в `.env.example`. Используются только LLM из списка кейса.
Дневной бюджет токенов контролируется модулем `app/services/token_budget.py`.

## Пошаговый сценарий проверки для жюри
1. Войти тестовым пользователем (`data/test_accounts.json`).
2. Выбрать клиента, главный экран показывает точку входа в сервис.
3. Открыть персонализированную ленту, убедиться, что она меняется при смене клиента.
4. Открыть карточку события: факты, почему важно, последствия, действия, позиция банка, источники.
5. Задать уточняющий вопрос, перейти к первоисточнику.
6. Открыть трассу агента (какие источники и признаки клиента повлияли на вывод).

## Данные
- `data/raw/` исходные CSV (не в git).
- `data/synthetic/` синтетические данные для воспроизводимой проверки.
- `data/bank_analytics/` материалы Альфа-Банка (Приложение 2).
