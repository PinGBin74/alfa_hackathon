# THIRD_PARTY_NOTICES

Перечень сторонних компонентов, моделей, датасетов, сервисов и смоделированных интеграций.
Версии зафиксированы в `backend/uv.lock` и `frontend/package-lock.json`.

## LLM (только из списка кейса)
Вызываются через OpenAI-совместимый прокси организаторов (`LLM_BASE_URL`); ID - как в `GET /v1/models` прокси.
Эмбеддинг-моделей в списке кейса нет, поэтому они не используются (поиск - BM25, `backend/app/rag/retriever.py`).

| Модель | ID в прокси | Назначение в решении |
|---|---|---|
| Gemma 4 26B A4B | `google/gemma-4-26b-a4b-it` | разметка новостей, план агента |
| GLM-5.3-Flash | `z-ai/glm-5.3-flash` | черновик инсайта |
| Qwen3.6 35B A3B | `qwen/qwen3.6-35b-a3b` | ответы на уточняющие вопросы (чат) |
| DeepSeek-V4.1-Flash | `deepseek/deepseek-v4.1-flash` | фактчекинг инсайта, извлечение позиций банка из аналитики (офлайн) |
| Kimi-K2.6 | `moonshotai/kimi-k2.6` | независимый LLM-судья в `eval/` (в генерации не участвует) |
| Qwen3-VL-30B-A3B-Instruct | `qwen/qwen3-vl-30b-a3b-instruct` | OCR таблиц и графиков в сканах аналитики банка (офлайн) |

## Библиотеки backend
FastAPI, Pydantic, SQLAlchemy, Alembic, psycopg, pgvector, httpx, feedparser, trafilatura, pypdf, networkx, APScheduler, pytest, ruff.

## Библиотеки frontend
React 19, React DOM, React Router 7 (MIT); сборка - Vite 6, @vitejs/plugin-react, TypeScript 5 (MIT/Apache-2.0).
Шрифт Golos Text (SIL Open Font License 1.1) подключается с Google Fonts; без сети - системный шрифт.
Docker-образы (версии зафиксированы): python:3.12.12-slim-bookworm, ghcr.io/astral-sh/uv:0.9.5,
pgvector/pgvector:0.8.7-pg16-bookworm, node:20.19.5-alpine, nginx:1.27.5-alpine.

## Датасеты
- Обезличенные данные о юрлицах, физлицах и платежах (предоставлены организаторами, Приложение 1).
- Аналитические материалы Центра макроэкономических исследований Альфа-Банка (Приложение 2).
- Синтетические тестовые данные: `data/synthetic/` (генератор `backend/app/db/synthetic.py`, seed 2026).
- Эталонная разметка для оценки (`eval/golden_*`): ручная и слепая разметка командой; тексты новостей в репозиторий
  не входят (авторское право), только заголовки, ссылки и разметка.

## Смоделированные интеграции
- Интерфейс интернет-банка Альфа-Бизнес: имитация (прототип). Остатки на счетах на главной - сгенерированные
  демо-значения; разделы «Счета», «Платежи», «Документы» не реализованы. Логотип - текстовая буква в красном
  квадрате, фирменные материалы банка не используются.
- Источники новостей (публичные RSS-ленты, полный текст - из ленты или со страницы статьи через trafilatura;
  реестр - `backend/app/ingestion/sources/__init__.py`): Банк России (пресс-релизы), Минфин России, Интерфакс
  (Экономика), РБК, ПРАЙМ (Бизнес), Коммерсантъ (Экономика, Бизнес), Ведомости (Экономика). Новость по ссылке
  (`POST /api/news`) - с любого публичного сайта. В `eval/fixtures/news_real.jsonl` хранятся только заголовки,
  ссылки и разметка, без текстов статей.
