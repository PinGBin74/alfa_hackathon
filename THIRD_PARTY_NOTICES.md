# THIRD_PARTY_NOTICES

Перечень сторонних компонентов, моделей, датасетов, сервисов и смоделированных интеграций.
Заполнять по мере добавления зависимостей. Версии зафиксированы в `backend/uv.lock` и `frontend/package-lock.json`.

## LLM (только из списка кейса)
| Модель | Назначение в решении |
|---|---|
| Gemma 4 26B A4B | классификация, извлечение фактов |
| GLM-5.3-Flash | интерпретация, самопроверка |
| Qwen3.6 35B A3B | универсальные задачи |
| DeepSeek-V4.1-Flash | анализ связей, большие объёмы |
| Kimi-K2.6 | обработка текста |
| Qwen3-VL-30B-A3B-Instruct | (не используется / мультимодальность) |

## Библиотеки backend
FastAPI, Pydantic, SQLAlchemy, Alembic, psycopg, pgvector, httpx, feedparser, trafilatura, pypdf, networkx, APScheduler, pytest, ruff.

## Библиотеки frontend
Заполнить после выбора стека.

## Датасеты
- Обезличенные данные о юрлицах, физлицах и платежах (предоставлены организаторами, Приложение 1).
- Аналитические материалы Центра макроэкономических исследований Альфа-Банка (Приложение 2).
- Синтетические тестовые данные: `data/synthetic/`.
