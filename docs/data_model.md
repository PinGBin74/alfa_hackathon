# Модель данных

Таблицы: `companies`, `persons`, `payments`, `news`, `analytics_docs`, `analytics_chunks`, `users`, `insights`, `agent_traces`, `token_usage`, `feedback`.
Определения: `backend/app/db/models.py`. Поля компаний соответствуют Приложению 1 задания.
`users` - тестовые учётные записи из `data/test_accounts.json` (`python -m app.db.seed` загружает их вместе с CSV):
роль и список доступных компаний; у одной компании несколько пользователей с разными ролями.
`insights.payload` - разбор по `contracts/insight.schema.json`, ключ кэша - (client_id, news_id, user_role);
`agent_traces` - шаги агента с моделью, токенами, временем и входом/выходом шага.

Синтетические данные (`data/synthetic/`, генератор `python -m app.db.synthetic`): те же 5 демо-клиентов, что в
`eval/fixtures/demo_profiles.json`, с близкими признаками (ОКВЭД, регион, выручка, продукты, ВЭД, группа, место в
отрасли, структура платежей), сгенерированные участники групп, компании отрасли (не больше 300 на класс) и
контрагенты; `news.jsonl` - 16 демо-новостей с готовой разметкой. Позволяют пройти сценарий без исходной выгрузки.

`news.ml_meta` (JSON) - полная разметка новости (`app/ml/news.py`: факторы с направлением, отрасли, регионы, страны,
компании, важность); у новостей, записанных до этой колонки, разметка восстанавливается из `event_type` и других колонок.
