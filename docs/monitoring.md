# Мониторинг качества

## Метрики
- Доля выводов с валидной ссылкой на источник.
- Доля инсайтов, прошедших verifier с первой итерации.
- Оценки пользователей (`/api/feedback`) и комментарии экспертов.
- Релевантность ленты: доля открытых карточек из топ-5.
- Расход токенов и стоимость в день, латентность (`agent_traces`, `token_usage`).

## Процесс
1. Еженедельно прогон `eval/run_eval.py` на golden set и на свежих новостях.
2. Разбор негативной обратной связи, правка промптов и весов ранжирования.
3. Регрессия перед каждым релизом.
