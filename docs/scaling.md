# Масштабирование и сопровождение

- **Новый источник новостей**: подкласс `NewsSource` в `ingestion/sources/`, регистрация в `SOURCES`.
- **Новая отрасль**: расширить словарь отраслей/событий (`ranking.py`, промпт классификации); код агента не меняется.
- **Новый тип клиентов**: новые признаки в `ClientProfile` + веса в `ranking.WEIGHTS`.
- **Новые аналитические материалы**: положить PDF в `data/bank_analytics/`, `make ingest`.
- **Сопровождение**: миграции Alembic, версионируемые промпты в git, eval-набор в `eval/`.
